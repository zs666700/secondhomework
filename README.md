# 小学四则运算题目生成器

用 Python 实现的四则运算题目自动生成与判分命令行程序。

## 运行环境

- Python 3.10 或更高（开发环境为 3.13.2）
- 仅使用标准库，无需安装任何第三方依赖

## 用法

### 生成题目
```
python myapp.py -n 10 -r 10
```

- `-n` 生成题目的个数，默认 10
- `-r` 题目中数值的范围上界（**不含**），生成模式下必须给定

命令在当前目录下生成两个文件：

- `Exercises.txt` —— 题目，每行一道，格式为 `<表达式> =`
- `Answers.txt` —— 与题目一一对应的答案，每行一个

### 判分

```
python myapp.py -e Exercises.txt -a Answers.txt
```

`-e` 与 `-a` 必须同时给出，且不能与 `-n` / `-r` 混用——混用会直接报错退出（退出码 2）。

在当前目录下生成 `Grade.txt`：

```
Correct: 5 (1, 3, 5, 7, 9)
Wrong: 5 (2, 4, 6, 8, 10)
```

## 题目规则

- 操作数是自然数，或真分数（分子 < 分母，分子分母都小于 `-r`）
- 每道题最多 3 个运算符
- 计算过程中不产生负数：`e1 - e2` 要求 `e1 >= e2`
- 除法结果必为真分数：`e1 ÷ e2` 要求 `0 < e1 < e2`
- 所有中间结果与最终答案都小于 `-r`
- 一次运行内生成的题目互不重复

### 关于「重复」的判定

题目 A 与题目 B 重复，当且仅当可以通过有限次**交换 `+` 或 `×` 的左右操作数**把 A 变成 B。
注意**不允许重新结合**，因此：

- `23 + 45` 与 `45 + 23` 重复
- `6 × 8` 与 `8 × 6` 重复
- `1+2+3` 与 `3+(2+1)` 重复（前者即 `(1+2)+3`）
- `1+2+3` 与 `3+2+1` **不重复**（前者是 `(1+2)+3`，后者是 `(3+2)+1`，交换无法互相转化）

## 书写格式

- 真分数写作 `3/5`
- 假分数输出时转成带分数：`19/8` 写作 `2’3/8`（分隔符是 U+2019）
- 判分时兼容多种写法：`2’3/8`、`2'3/8`、`13/8` 都算对
- 运算符输出为 `+`、`-`、`×`、`÷`；输入时额外兼容 `−`(U+2212)、`–`(U+2013)、`*`

## 退出码

| 码 | 含义 |
|---|---|
| 0 | 成功（包括判分时个别题目无法解析——那只是计错并警告，不影响退出码） |
| 1 | 在给定 `-r` 下可选题目已耗尽，只生成了部分题目 |
| 2 | 参数错误，或文件错误（不存在、无法按 UTF-8 读取） |

判分时若某道题在题目文件里无法解析，该题计为错误、向 stderr 打警告，程序继续处理，退出码仍为 0。

## 运行测试

```
python -m unittest discover -s tests -t . -v
```

## 项目结构

```
myapp.py              命令行入口
four_ops/
  __init__.py
  fraction_util.py    分数文本与 Fraction 互转
  expression.py       表达式树：求值、合法性、规范键、渲染
  parser.py           表达式文本 -> 表达式树
  generator.py        题目生成与去重
  grader.py           判分
  cli.py              参数校验与文件读写
tests/                单元测试（6 个测试文件，共 123 个用例）
```
